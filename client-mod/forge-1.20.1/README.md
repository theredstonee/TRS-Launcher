# TRS Client – Minecraft 1.20.1 (Forge)

The Forge build of the TRS Client for 1.20.1 modpacks (Create, ATM 9, …). Same features, look and config file as the
Fabric build (see `../README.md`): HUD (FPS, CPS, Keystrokes, Ping) with drag editor, Zoom (hold C), Fullbright,
Right-Shift menu, key bindings under **TRS Client**, "Config" button in the mod list opens the TRS menu.
Settings: `config/trsclient.json`. License: GPL-3.0-only, author: theredstonee.

Client-only (`displayTest = "IGNORE_ALL_VERSION"`, the `@Mod` class does nothing on a dedicated server).

| Feature | Hook |
| --- | --- |
| HUD | overlay via `RegisterGuiOverlaysEvent#registerAboveAll` |
| Zoom | `ViewportEvent.ComputeFov` (only when `usedConfiguredFov()`, so the hand is not zoomed) |
| Zoom scroll | `InputEvent.MouseScrollingEvent` (cancelled while zooming → hotbar stays) |
| CPS | `InputEvent.MouseButton.Pre` |
| Slower mouse while zooming | Mixin `MouseHandler#turnPlayer` (HEAD): divides the accumulated mouse delta – Forge 1.20.1 has no turn event |
| Fullbright | Mixin `LightTexture#updateLightTexture`: `@Redirect` of the single `Double#floatValue()` after `options.gamma()` (Forge 1.20.1 ships no MixinExtras). The vanilla option is never changed. |
| Keys / tick / save | `RegisterKeyMappingsEvent`, `TickEvent.ClientTickEvent` (END), `GameShuttingDownEvent` |

Mixins are declared through the `MixinConfigs` manifest attribute; the refmap (`trsclient.refmap.json`, SRG names)
is generated by the Mixin annotation processor and `reobfJar` remaps the `@Shadow` fields.
Uses the static `FMLJavaModLoadingContext.get()` / `ModLoadingContext.get()` on purpose (deprecated since 47.3, but they
work on every 47.x build that modpacks still use).

## Build

Standalone Gradle build (not part of `../settings.gradle`):

```sh
./gradlew build                     # builds, runs unit tests, copies the jar to ../dist/
./gradlew runClient                 # dev client (game dir: ../run/forge-1.20.1)
./gradlew runClient -PtrsAutotest   # self-test: menu, test world, screenshots, quits
```

- Gradle 9.5.1, ModDevGradle Legacy-Forge `net.neoforged.moddev.legacyforge` 2.0.147 (instead of ForgeGradle 6,
  which does not support Gradle 9), Forge 1.20.1-47.4.10 (recommended), Mixin AP 0.8.5, Java 17 toolchain (foojay).
- Output: `build/libs/trsclient-forge-1.20.1-<version>.jar` (reobfuscated to SRG names by `reobfJar`),
  copied by `collectLauncherJars` (runs after `build`) to `../dist/trsclient-forge-1.20.1.jar`
  together with `../dist/builds-forge-1.20.1.json`.
- Self-test screenshots: `../run/forge-1.20.1/screenshots/trsclient-forge-1.20.1-*.png`.

## Shared code

`../common/src/main/java` is added as a **source directory** – `common` only uses Java 17 language features
(`sealed`, records), so no copy is needed; its unit tests run here on Java 17 against Gson 2.10.
`hud/`, `screen/`, `ui/` are adapted copies of the Fabric 1.21.1 classes. 1.20.1 differences: `Screen#render` does not
draw the background itself, `renderBackground(GuiGraphics)` / `renderDirtBackground`, 3-argument `mouseScrolled`,
no `DeltaTracker`.

## Installing via the launcher

Forge 1.20.1 instance → put `trsclient-forge-1.20.1.jar` into `mods/`. No other dependencies (`requires: []`).
Declared ranges: `minecraft [1.20.1]`, `forge [47,)`.
