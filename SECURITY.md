# Security Policy

## Supported versions

Only the **newest release** of the TRS Launcher and the TRS Client gets security fixes. Both update themselves, so
please check that you are on the latest version before you report something.

| Version | Supported |
|---|---|
| Newest release ([Releases](https://github.com/theredstonee/TRS-Launcher/releases)) | Yes |
| Older releases | No |

## Reporting a vulnerability

**Please do not report security problems in public** – not in the website tracker, not in Discussions and not on
Discord.

Report them privately through GitHub instead:
[**Report a vulnerability**](https://github.com/theredstonee/TRS-Launcher/security/advisories/new) (tab *Security* →
*Report a vulnerability*). Only the maintainer can see the report.

Please include:

- what is affected (launcher, TRS Client, website/TRS API) and which version,
- how to reproduce it, and what an attacker could do with it,
- a proof of concept if you have one.

You will get an answer as soon as possible. Once a fix is released, the advisory is published and – if you want – you
are credited for the report. Please give us a reasonable amount of time to fix the problem before you talk about it
publicly.

Things that are **not** security problems on their own: missing security headers on pages without sensitive content,
reports from automated scanners without a working attack, and the SmartScreen warning of the unsigned Windows
installer (see the README).
