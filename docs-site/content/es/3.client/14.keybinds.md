## Teclas en los controles de Minecraft

Estas teclas están en **Opciones → Controles → Asignar teclas**, en la categoría **TRS Client**. Cámbialas ahí; zoom, vista libre y mapa del mundo también se pueden cambiar en sus páginas de módulo, es el mismo ajuste.

| Acción | Tecla predeterminada | Nota |
| --- | --- | --- |
| Abrir menú TRS | :kbd{value="Mayús derecha"} | |
| Zoom (mantener) | :kbd{value="V"} | |
| Vista libre | :kbd{value="Alt izquierda"} | no en 1.7.10, 1.13.2, Forge 1.14.4 |
| Rueda de emotes (mantener) | :kbd{value="R"} | no en 1.7.10, 1.13.2, Forge 1.14.4 |
| Mapa del mundo | :kbd{value="M"} | sin asignar si otro mod de mapas ya usa la M |
| Alternar superposición de señal | :kbd{value="F6"} | :kbd{value="F8"} en 1.7.10 y 1.8.9 |
| Guardar clip | :kbd{value="F9"} | necesita TRS Launcher |
| Iniciar/detener grabación | :kbd{value="F10"} | necesita TRS Launcher |
| Respuesta rápida / unirse | :kbd{value="Y"} | no en 1.7.10, 1.13.2 |
| Activar/desactivar fullbright | sin asignar | |
| Cambiar perfil de HUD | sin asignar | |
| Abrir vestuario | sin asignar | |
| Abrir social | sin asignar | no en 1.7.10, 1.13.2 |
| Tomar panorámica | sin asignar | 1.8.9 – 1.12.2 y desde 1.17 |
| Abrir notas | sin asignar | |

::tip
Desde 1.8.9 puedes escribir `mod:trsclient` o `conflicto` en el campo de búsqueda de los controles para encontrar rápido las teclas de TRS o los choques. Ver [Buscar en los controles](/es/client/chat-and-comfort#buscar-en-los-controles).
::

## Teclas en las páginas de módulos

Estas teclas se ajustan en el menú TRS, en la página de cada módulo. No están en los controles de Minecraft.

| Módulo | Acción | Tecla predeterminada |
| --- | --- | --- |
| Puntos de ruta | Crear punto de ruta | :kbd{value="B"} |
| Puntos de ruta | Abrir puntos de ruta | :kbd{value="N"} |
| Biblioteca de circuitos | Girar al colocar | :kbd{value="R"} |
| Biblioteca de circuitos | Confirmar posición | :kbd{value="Enter"} |
| Biblioteca de circuitos | Capa siguiente / Capa anterior | :kbd{value="↑"} / :kbd{value="↓"} |
| Biblioteca de circuitos | Ocultar/mostrar plantilla | :kbd{value="H"} |
| Biblioteca de circuitos | Abrir la biblioteca | sin asignar |
| Modo streamer | Tecla para alternar | sin asignar |
| Atajos de texto | Tecla 1 – 4 | sin asignar |

## Teclas dentro de las pantallas

| Pantalla | Tecla | Acción |
| --- | --- | --- |
| Menú TRS | :kbd{value="Esc"} | Borra la búsqueda |
| Editor HUD | :kbd{value="Mayús"} al arrastrar | Colocar libremente sin ajuste |
| Editor HUD | Rueda del ratón / clic derecho | Tamaño / restablecer posición |
| Rueda de emotes | tocar :kbd{value="R"}, luego :kbd{value="Esc"} | Modo clic, cerrar |
| Editor de capturas | :kbd{value="Z"} / :kbd{value="Y"} | Deshacer / rehacer |
| Editor de skins | :kbd{value="B"} :kbd{value="E"} :kbd{value="I"} :kbd{value="G"} :kbd{value="M"} | Pincel, borrador, cuentagotas, rellenar, espejo |
| Editor de skins | :kbd{value="Z"} / :kbd{value="Y"} | Deshacer / rehacer |
| Respuesta rápida | :kbd{value="Enter"} / :kbd{value="Mayús"} + :kbd{value="Enter"} / :kbd{value="Esc"} | Enviar / nueva línea / cerrar |

La tecla :kbd{value="F2"} de Minecraft sigue haciendo capturas; TRS Client añade la [vista previa y el editor](/es/client/screenshots-and-clips).
