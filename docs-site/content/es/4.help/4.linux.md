El TRS Launcher funciona en cualquier Linux x86_64 con glibc 2.35 o más nuevo (Ubuntu 22.04+, Debian 12+, Fedora 36+,
Arch, openSUSE Tumbleweed y otros), con Wayland y X11. Java se descarga automáticamente. Esta página explica qué cambia
en Linux y cómo resolver los problemas típicos; la instalación se explica en [Instalación](/es/getting-started/installation).

## Dónde está cada cosa

| Qué | Ruta |
|---|---|
| Datos del launcher (instancias, Java, bibliotecas) | `~/.local/share/TRS-Launcher` |
| Datos del launcher (Flatpak) | `~/.var/app/dev.theredstonee.trslauncher/data/TRS-Launcher` |
| Registro del launcher | `~/.local/share/dev.theredstonee.trslauncher/logs` |
| Clave de inicio de sesión | el llavero del sistema (Secret Service); si no, `~/.local/share/TRS-Launcher/.token-key` (permisos 0600) |

## Actualizaciones

Solo el **AppImage** se actualiza solo, como la versión de Windows. Los paquetes `.deb`, `.rpm`, AUR y Flatpak los
actualiza tu gestor de paquetes; el launcher te avisa cuando hay una versión nueva («Actualización … disponible») y la
enlaza.

## Claves de inicio de sesión y llavero

La clave que protege tus inicios de sesión de Microsoft se guarda en el llavero del sistema (GNOME Keyring, KWallet,
KeePassXC con Secret Service…). Sin llavero, se guarda en un archivo que solo tu usuario puede leer.

**Ajustes → Almacenamiento → Inicios de sesión guardados** muestra qué se usa. Si pone **Solo permisos de archivo**:

::steps{level="3"}

### Configura un llavero

Instala y desbloquea GNOME Keyring o KWallet, o activa el Secret Service en KeePassXC.

### Reinicia el launcher

La clave se mueve sola al llavero.

::

## Solución de problemas

### Ventana vacía o blanca

Inicia el launcher con el renderizador DMA-BUF de WebKit desactivado:

```bash
WEBKIT_DISABLE_DMABUF_RENDERER=1 trs-launcher
```

Con el controlador propietario de NVIDIA, el launcher lo hace solo. En tarjetas gráficas muy antiguas prueba además
`WEBKIT_DISABLE_COMPOSITING_MODE=1`.

### El AppImage no arranca («FUSE»)

El AppImage necesita FUSE 2. Instálalo o ejecuta el AppImage sin FUSE:

::code-group

```bash [Debian/Ubuntu]
sudo apt install libfuse2
```

```bash [Arch]
sudo pacman -S fuse2
```

```bash [Sin FUSE]
./TRS-Launcher_<version>_amd64.AppImage --appimage-extract-and-run
```

::

### Minecraft 1.12.2 o anterior se cierra al arrancar

Las versiones antiguas (LWJGL 2) necesitan la herramienta `xrandr`:

::code-group

```bash [Arch]
sudo pacman -S xorg-xrandr
```

```bash [Debian/Ubuntu]
sudo apt install x11-xserver-utils
```

```bash [Fedora]
sudo dnf install xrandr
```

::

### El juego usa la tarjeta gráfica equivocada

En un portátil con dos chips gráficos, activa **Ajustes → Ajustes predeterminados → Tarjeta gráfica de alto
rendimiento**. El launcher pone entonces `DRI_PRIME=1` (AMD/Intel) o las variables de NVIDIA PRIME. Tus propios valores
en **Variables de entorno** tienen prioridad.

### Herramientas como GameMode o prime-run

Ponlas delante del juego en **Ajustes → Hooks de inicio → Wrapper**, por ejemplo `gamemoderun` o `prime-run`.

### Importar desde otros launchers

Prism Launcher, MultiMC, la Modrinth App y `~/.minecraft` se encuentran automáticamente, también sus versiones Flatpak.

::note
La versión Flatpak solo puede leer estas carpetas conocidas. Para todo lo demás, usa **Examinar carpeta** en el diálogo
de importación.
::

## Wayland

El launcher funciona con Wayland y X11. El juego en sí se ejecuta a través de XWayland.

## No disponible en Linux

- **Grabación de clips** y la **excepción del firewall de Windows** (en Linux no hace falta).
- **ARM64**: no hay builds para ARM, porque Mojang no tiene runtime de Java para Linux ARM y Minecraft 1.12.2 y
  anteriores no tienen natives para ARM.
