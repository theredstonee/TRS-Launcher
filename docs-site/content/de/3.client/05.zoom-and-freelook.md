## Zoom

Halte :kbd{value="V"}, um weich heranzuzoomen. Solange du die Taste hältst, ändert das **Mausrad** den Zoom, und die Maus wird mit langsamer. Beim Blick durchs Fernrohr pausiert der Zoom. Ab Werk an, in jeder Minecraft-Version.

![Herangezoomte Sicht beim Halten von V](/shots/client/zoom.png)

| Einstellung | Standard |
| --- | --- |
| Zoom-Faktor | 4× (2× – 10×) |
| Weicher Übergang | an |
| Mausrad ändert Zoom | an |
| Maus verlangsamen | an |
| Filmische Kamera (nur beim Zoomen) | aus |

::tip
Die Zoom-Taste ist eine normale Minecraft-Tastenbelegung (**Optionen → Steuerung → Tastenbelegung → TRS Client → Zoom (halten)**). Ob du sie dort oder auf der Modulseite änderst, ist dasselbe. V ist in jeder Vanilla-Version frei – C würde sich mit „Schnellzugriffsleiste speichern“ überschneiden.
::

## Freelook

Halte :kbd{value="Alt links"}, um die Kamera um deine Figur kreisen zu lassen. Du läufst weiter geradeaus, und der Server sieht immer nur deine echte Blickrichtung. Ab Werk aus – schalte es in der Kategorie **Welt** ein.

::steps
### Einschalten
TRS-Menü → **Welt** → **Freelook**.

### Verhalten wählen
**Umschalten statt Halten** schaltet Freelook mit einem Druck um. **Perspektive** setzt die Kamera **Hinten** oder **Vorne** hin.

### Server eintragen, auf denen es aus bleibt
**Aus auf diesen Servern** nimmt eine Liste mit `;` getrennt, zum Beispiel `example.net;other.org`. Subdomains zählen mit; `*.example.net` heißt nur die Subdomains. Auf diesen Servern schaltet sich Freelook selbst ab, und eine Meldung sagt es dir.
::

::warning
Manche Server verbieten Freelook. Halte dich an die Server-Regeln.
::

## Toggle-Sprint und Toggle-Schleichen

Drück die Sprint- oder Schleichen-Taste einmal, um dauerhaft zu sprinten oder zu schleichen, und noch einmal zum Aufhören. Das HUD zeigt den Zustand, zum Beispiel **[Sprinten (umgeschaltet)]** oder **[Schleichen (Taste gehalten)]**.

| Einstellung | Modul | Standard |
| --- | --- | --- |
| Sprinten nur vorwärts | Toggle-Sprint | an |
| Zustand merken (Tod, Weltwechsel) | Toggle-Sprint | an |
| Flug-Boost (Kreativmodus) | Toggle-Sprint | aus, 2× wenn an |
| Zustand merken (Tod, Weltwechsel) | Toggle-Schleichen | aus |

Beide Module sind ab Werk aus und liegen in der Kategorie **PvP**.

## Versions-Hinweise

::note
Zoom, Toggle-Sprint und Toggle-Schleichen laufen in jeder Version. Freelook gibt es nicht auf 1.7.10, 1.13.2 und Forge 1.14.4.
::
