## Tasten in der Minecraft-Steuerung

Diese Tasten stehen unter **Optionen → Steuerung → Tastenbelegung** in der Kategorie **TRS Client**. Ändere sie dort – Zoom, Freelook und Weltkarte lassen sich auch auf ihren Modulseiten ändern, das ist dieselbe Einstellung.

| Aktion | Standard-Taste | Hinweis |
| --- | --- | --- |
| TRS-Menü öffnen | :kbd{value="Umschalt rechts"} | |
| Zoom (halten) | :kbd{value="V"} | |
| Freelook | :kbd{value="Alt links"} | nicht auf 1.7.10, 1.13.2, Forge 1.14.4 |
| Emote-Rad (halten) | :kbd{value="R"} | nicht auf 1.7.10, 1.13.2, Forge 1.14.4 |
| Weltkarte | :kbd{value="M"} | unbelegt, wenn schon eine andere Karten-Mod M nutzt |
| Signal-Overlay umschalten | :kbd{value="F6"} | :kbd{value="F8"} auf 1.7.10 und 1.8.9 |
| Clip speichern | :kbd{value="F9"} | braucht den TRS Launcher |
| Aufnahme starten/stoppen | :kbd{value="F10"} | braucht den TRS Launcher |
| Schnellantwort / Beitreten | :kbd{value="Y"} | nicht auf 1.7.10, 1.13.2 |
| Fullbright umschalten | unbelegt | |
| HUD-Profil wechseln | unbelegt | |
| Garderobe öffnen | unbelegt | |
| Sozial öffnen | unbelegt | nicht auf 1.7.10, 1.13.2 |
| Panorama aufnehmen | unbelegt | 1.8.9 – 1.12.2 und ab 1.17 |
| Notizen öffnen | unbelegt | |

::tip
Ab 1.8.9 kannst du `mod:trsclient` oder `konflikt` ins Suchfeld der Tastenbelegung tippen, um TRS-Tasten oder Überschneidungen schnell zu finden. Siehe [Tastenbelegungs-Suche](/de/client/chat-and-comfort#tastenbelegungs-suche).
::

## Tasten auf Modulseiten

Diese Tasten stellst du im TRS-Menü auf der Seite des jeweiligen Moduls ein. Sie stehen nicht in der Minecraft-Steuerung.

| Modul | Aktion | Standard-Taste |
| --- | --- | --- |
| Wegpunkte | Wegpunkt anlegen | :kbd{value="B"} |
| Wegpunkte | Wegpunkte öffnen | :kbd{value="N"} |
| Schaltungs-Bibliothek | Drehen beim Platzieren | :kbd{value="R"} |
| Schaltungs-Bibliothek | Position bestätigen | :kbd{value="Enter"} |
| Schaltungs-Bibliothek | Nächste Schicht / Vorige Schicht | :kbd{value="↑"} / :kbd{value="↓"} |
| Schaltungs-Bibliothek | Vorlage aus-/einblenden | :kbd{value="H"} |
| Schaltungs-Bibliothek | Bibliothek öffnen | unbelegt |
| Streamer-Modus | Taste zum Umschalten | unbelegt |
| Text-Hotkeys | Taste 1 – 4 | unbelegt |

## Tasten in Bildschirmen

| Bildschirm | Taste | Aktion |
| --- | --- | --- |
| TRS-Menü | :kbd{value="Esc"} | Leert die Suche |
| HUD-Editor | :kbd{value="Umschalt"} beim Ziehen | Frei platzieren ohne Einrasten |
| HUD-Editor | Mausrad / Rechtsklick | Größe / Position zurücksetzen |
| Emote-Rad | :kbd{value="R"} kurz antippen, dann :kbd{value="Esc"} | Klick-Modus, schließen |
| Screenshot-Editor | :kbd{value="Z"} / :kbd{value="Y"} | Rückgängig / Wiederholen |
| Skin-Editor | :kbd{value="B"} :kbd{value="E"} :kbd{value="I"} :kbd{value="G"} :kbd{value="M"} | Pinsel, Radierer, Pipette, Füllen, Spiegeln |
| Skin-Editor | :kbd{value="Z"} / :kbd{value="Y"} | Rückgängig / Wiederholen |
| Schnellantwort | :kbd{value="Enter"} / :kbd{value="Umschalt"} + :kbd{value="Enter"} / :kbd{value="Esc"} | Senden / neue Zeile / schließen |

Minecrafts eigenes :kbd{value="F2"} macht weiterhin Screenshots – der TRS Client ergänzt [Vorschau und Editor](/de/client/screenshots-and-clips).
