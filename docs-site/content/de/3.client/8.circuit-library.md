Die **Schaltungs-Bibliothek** ist eine Seite in der Kategorie **Redstone** mit fertigen Schaltungen: Logikgatter, Verstärker-Kette, Fackelturm, Takte, Speicher (RS-Latch, T-Flipflops, D-Latch), Puls-Schaltungen, eine 2×2-Kolbentür und eine versteckte Treppe, Farm-Grundlagen (Zuckerrohr, Item-Filter, automatischer Ofen, Item-Aufzug) und Anzeigen.

::note
Die Schaltungs-Bibliothek gibt es ab Minecraft 1.8.9 (nicht auf 1.7.10 und 1.13.2). Die Schaltungen kommen vom TRS-Server, neue erscheinen also ohne Mod-Update. Die Bibliothek prüft einmal je Start auf Änderungen und behält eine Kopie für offline – vor dem allerersten Laden braucht sie Internet.
::

![Die Schaltungs-Bibliothek mit 3D-Vorschau und Materialliste einer Schaltung](/shots/client/circuits-library.png)

## Eine Schaltung finden

Öffne das TRS-Menü → **Redstone** → **Schaltungs-Bibliothek** → **Bibliothek öffnen**. Auf der Modulseite kannst du auch eine Taste **Bibliothek öffnen** festlegen (ab Werk unbelegt).

- **Suche** und Kategorien helfen beim Finden, **Meine Version** blendet aus, was deine Minecraft-Version nicht bauen kann.
- Jede Schaltung hat eine Erklärung, Schwierigkeit, Größe, die nötige Minecraft-Version und ob sie auf Servern zuverlässig läuft.
- Die Liste **Material** zeigt, wie viel von jedem Block du schon im Inventar hast.
- Die 3D-Vorschau lässt sich drehen und Schicht für Schicht ansehen.

## Eine Schaltung als Vorlage einblenden

::steps
### Vorlage platzieren
Klick auf **Als Vorlage einblenden**. Die Vorlage folgt deinem Blick – :kbd{value="R"} dreht sie, :kbd{value="Enter"} bestätigt die Position.

### Block für Block bauen
Geisterblöcke zeigen, was wohin gehört:
- **grün** – der Block stimmt,
- **rot** – der Block ist falsch (mit Grund),
- **grau** – der Block fehlt noch.

Ein Fortschrittsbalken zeigt „32/40 Blöcke“.

### Schicht für Schicht arbeiten
:kbd{value="↑"} und :kbd{value="↓"} wechseln zur nächsten oder vorigen Schicht, :kbd{value="H"} blendet die Vorlage aus oder ein.

### Entfernen
Wenn du fertig bist, klick in der Bibliothek oder auf der Modulseite auf **Vorlage entfernen**.
::

![Geisterblöcke einer Vorlage in der Welt, grün, rot und grau](/shots/client/circuits-ghost.png)

Die Vorlage bleibt in der Welt oder auf dem Server, auch wenn du neu verbindest. Der Knopf **Gespiegelt** neben **Als Vorlage einblenden** spiegelt die Schaltung, bevor du sie platzierst.

::tip
Die Vorlage ist nur Anzeige, wie eine Schematic-Vorschau: Nichts wird für dich gebaut und nichts an den Server geschickt – unkritisch auf Servern mit Fair-Play-Regeln oder Anti-Cheat.
::

### Einstellungen

Blocknamen an fehlenden und falschen Blöcken, Deckkraft der Geisterblöcke, **Richtige Blöcke nur umranden** und die Tasten zum Drehen, Bestätigen, für die Schichten und zum Ausblenden.

## Eigene Schaltung einreichen

Dafür musst du mit den TRS-Online-Funktionen angemeldet sein.

::steps
### Bereich markieren
Klick auf **Eigene Schaltung einreichen** → **Bereich markieren**. Schau eine Ecke an und bestätige, dann die gegenüberliegende Ecke. Der Bereich darf bis zu 16×16×16 Blöcke groß sein. Gelesen werden nur die Blöcke – keine Truhen-Inhalte.

### Beschreiben
Gib einen **Namen**, eine **Kategorie** und eine **Kurze Beschreibung** an.

### Einreichen
Klick auf **Einreichen**. Das TRS-Team prüft jede Einreichung, bevor sie in der Bibliothek aller erscheint. Reiche nur eigene Entwürfe ein.
::

**Meine Einreichungen** zeigt, ob jede Schaltung gerade geprüft wird, angenommen oder abgelehnt wurde (mit Grund).
