## Keys in the Minecraft controls

These keys are in **Options → Controls → Key Binds** under the category **TRS Client**. Change them there – zoom, freelook and world map can also be changed on their module pages, it is the same setting.

| Action | Default key | Notes |
| --- | --- | --- |
| Open TRS menu | :kbd{value="Right Shift"} | |
| Zoom (hold) | :kbd{value="V"} | |
| Freelook | :kbd{value="Left Alt"} | not on 1.7.10, 1.13.2, Forge 1.14.4 |
| Emote wheel (hold) | :kbd{value="R"} | not on 1.7.10, 1.13.2, Forge 1.14.4 |
| World map | :kbd{value="M"} | unbound if another map mod already uses M |
| Toggle signal overlay | :kbd{value="F6"} | :kbd{value="F8"} on 1.7.10 and 1.8.9 |
| Save clip | :kbd{value="F9"} | needs the TRS Launcher |
| Start/stop recording | :kbd{value="F10"} | needs the TRS Launcher |
| Quick reply / join | :kbd{value="Y"} | not on 1.7.10, 1.13.2 |
| Toggle fullbright | unbound | |
| Switch HUD profile | unbound | |
| Open wardrobe | unbound | |
| Open social | unbound | not on 1.7.10, 1.13.2 |
| Take panorama | unbound | 1.8.9 – 1.12.2 and 1.17+ |
| Open notes | unbound | |

::tip
From 1.8.9 on you can type `mod:trsclient` or `conflict` into the search box of the key binds screen to find TRS keys or clashes quickly. See [Key bind search](/en/client/chat-and-comfort#key-bind-search).
::

## Keys on module pages

These keys are set in the TRS menu on the module's own page. They are not in the Minecraft controls.

| Module | Action | Default key |
| --- | --- | --- |
| Waypoints | Create waypoint | :kbd{value="B"} |
| Waypoints | Open waypoints | :kbd{value="N"} |
| Circuit Library | Rotate while placing | :kbd{value="R"} |
| Circuit Library | Confirm position | :kbd{value="Enter"} |
| Circuit Library | Next layer / Previous layer | :kbd{value="↑"} / :kbd{value="↓"} |
| Circuit Library | Hide / show template | :kbd{value="H"} |
| Circuit Library | Open the library | unbound |
| Streamer Mode | Toggle key | unbound |
| Text Hotkeys | Key 1 – 4 | unbound |

## Keys inside screens

| Screen | Key | Action |
| --- | --- | --- |
| TRS menu | :kbd{value="Esc"} | Clears the search |
| HUD editor | :kbd{value="Shift"} while dragging | Place freely without snapping |
| HUD editor | Mouse wheel / right-click | Size / reset position |
| Emote wheel | tap :kbd{value="R"}, then :kbd{value="Esc"} | Click mode, close |
| Screenshot editor | :kbd{value="Z"} / :kbd{value="Y"} | Undo / redo |
| Skin editor | :kbd{value="B"} :kbd{value="E"} :kbd{value="I"} :kbd{value="G"} :kbd{value="M"} | Brush, eraser, eyedropper, fill, mirror |
| Skin editor | :kbd{value="Z"} / :kbd{value="Y"} | Undo / redo |
| Quick reply | :kbd{value="Enter"} / :kbd{value="Shift"} + :kbd{value="Enter"} / :kbd{value="Esc"} | Send / new line / close |

Minecraft's own :kbd{value="F2"} still takes screenshots – the TRS Client adds the [preview and editor](/en/client/screenshots-and-clips).
