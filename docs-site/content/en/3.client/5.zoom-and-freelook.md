## Zoom

Hold :kbd{value="V"} to zoom in smoothly. While you hold the key, the **mouse wheel** changes the zoom, and the mouse slows down with it. Zoom pauses while you look through a spyglass. On by default, in every Minecraft version.

![Zoomed view while holding V](/shots/client/zoom.png)

| Setting | Default |
| --- | --- |
| Zoom factor | 4× (2× – 10×) |
| Smooth transition | on |
| Mouse wheel changes zoom | on |
| Slow down mouse | on |
| Cinematic camera (only while zooming) | off |

::tip
The zoom key is a normal Minecraft key binding (**Options → Controls → Key Binds → TRS Client → Zoom (hold)**). Changing it there or on the module page is the same thing. V is free in every vanilla version – C would clash with "Save Hotbar Activator".
::

## Freelook

Hold :kbd{value="Left Alt"} to orbit the camera around your character. You keep walking and looking straight ahead, and the server only ever sees your real view direction. Off by default – turn it on in the category **World**.

::steps
### Turn it on
TRS menu → **World** → **Freelook**.

### Choose how it works
**Toggle instead of hold** switches freelook with one press. **Perspective** puts the camera **Behind** or **In front** of you.

### Add servers where it should stay off
**Off on these servers** takes a list separated by `;`, for example `example.net;other.org`. Subdomains count too; `*.example.net` means only the subdomains. On these servers freelook switches itself off and a message tells you.
::

::warning
Some servers forbid freelook. Respect the server rules.
::

## Toggle sprint and toggle sneak

Press the sprint or sneak key once to keep sprinting or sneaking, press it again to stop. The HUD shows the state, for example **[Sprinting (Toggled)]** or **[Sneaking (Key held)]**.

| Setting | Module | Default |
| --- | --- | --- |
| Sprint only forward | Toggle Sprint | on |
| Remember state (death, world change) | Toggle Sprint | on |
| Fly boost (creative mode) | Toggle Sprint | off, 2× when on |
| Remember state (death, world change) | Toggle Sneak | off |

Both modules are off by default and sit in the category **PvP**.

## Version notes

::note
Zoom, toggle sprint and toggle sneak work in every version. Freelook is not available on 1.7.10, 1.13.2 and Forge 1.14.4.
::
