An **instance** is a separate Minecraft installation with its own version, mods, worlds and settings. You can have as many as you like – for example one for the newest release, one for 1.8.9 PvP and one for a big modpack.

## Create an instance

::steps{level="3"}
### Open "New instance"
Click **New instance** in the left sidebar, in the [Library](/en/launcher/instances) or on the home page – or press :kbd{value="Ctrl"} :kbd{value="N"}.

### Name, version and mod loader
Give the instance a **Name**, pick the **Minecraft version** and a **Mod loader**: **Vanilla**, **Fabric**, **Quilt**, **Forge** or **NeoForge**. Tick **Snapshots & old versions** to see snapshots and very old releases too. Not sure which loader? See [Mod loaders](/en/launcher/mod-loaders).

### Presets (optional)
Below you can tick presets such as the **FPS boost** or **Voice chat**. They are installed wherever they exist for your version – see [Mods](/en/launcher/mods#presets).

### Create
Click **Create**. The instance appears in your library right away.
::

![The "New instance" dialog with version, mod loader and presets](/shots/getting-started/new-instance.png)

::tip
**Vanilla with more FPS:** vanilla instances start with the **TRS optimization** – Fabric, the TRS Client and performance mods like Sodium run under the hood. You still play plain Minecraft, just faster. If you want pure vanilla, turn it off in the instance settings under **Installation → TRS optimization**.
::

## Play

::steps{level="3"}
### Press Play
Click **Play** on the instance card, on the instance page or on the big lamp on the home page.

### The launcher prepares everything
On the first start the launcher downloads what's missing – version data, Java, the mod loader, libraries and game files. You see the progress in percent; the redstone line on the home page charges up while the game starts.

### The game runs
When Minecraft is running, the lamp glows. The title bar shows how many instances are running. Click **Stop game** if you need to end it.
::

![The home page while the game is starting](/shots/getting-started/play-starting.png)

::note
The first start of a version takes a moment because of the downloads. Later starts are much faster – game files and Java are shared between instances.
::

## Good to know

- You can close the launcher while you play – the game keeps running, and the launcher picks it up again on the next start.
- Downloads and installs run in the background. The tasks button in the title bar shows everything that's running, with pause and cancel.
- **Jump back in** on the home page starts your last played instance.
